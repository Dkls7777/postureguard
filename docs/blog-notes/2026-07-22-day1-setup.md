# Day 1: Dev environment setup

Date: 2026-07-22

## What I did
- Set up the dev environment on WSL2 (Ubuntu 26.04) under Windows
- Installed Docker Compose plugin, Node.js 22, confirmed Python 3.14 and Git
- Initialized the PostureGuard Git repository and docs structure

## Why these tools
- WSL2 + Ubuntu: run a real Linux environment on Windows for prod-like development
- Docker: run PostgreSQL in an isolated container instead of installing it on the host
- Node.js: runtime for the Next.js web app
- Python: language for the async scanning worker

## Gotchas and lessons
- Reset a forgotten WSL sudo password from Windows PowerShell: run "wsl -d Ubuntu -u root" then "passwd <user>"
- On a very fresh Ubuntu, "docker compose" needs the "docker-compose-v2" package installed separately
